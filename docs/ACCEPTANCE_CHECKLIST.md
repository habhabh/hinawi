# قائمة القبول

## المنتج والبيانات

- [x] Next.js App Router وTypeScript strict وRTL وMobile-first.
- [x] PostgreSQL/Drizzle schema وعلاقات مشروع مركزي مع عدة بائعين.
- [x] SQL migrations وseed عربي محلي.
- [x] Better Auth، تسجيل دخول/خروج/استعادة، تعطيل التسجيل العام، وأدوار خادمية.
- [x] CRUD إنشاء أساسي وقوائم للبائعين والأقسام والمشاريع مع audit transactions.
- [x] مكتبة وسائط، local/S3 upload، jobs وworker وSharp/FFmpeg.
- [x] صفحة البائع، الأقسام، شبكة 3 أعمدة، viewer، video وbefore/after وCTA.
- [x] QR ثابت وattribution وتحليلات privacy-conscious.
- [x] robots/sitemap/canonical/metadata/JSON-LD/Open Graph/PWA.

## التشغيل

- [x] Dockerfile multi-stage وnon-root وhealthcheck وstandalone.
- [x] compose محلي وvolume دائم.
- [x] GitHub Actions مع PostgreSQL service.
- [x] توثيق Coolify والنسخ والrollback.
- [ ] توسيع واجهات التعديل والأرشفة وإعادة الترتيب إلى جميع عمليات CRUD التفصيلية.
- [ ] عارض رأسي متعدد المشاريع؛ العارض الحالي أفقي داخل المشروع ويستخدم صفحات مستقلة بين المشاريع.
- [ ] توليد/تنزيل بطاقة QR بصيغتي SVG وPNG من الواجهة.

تُحدث نتائج أوامر التحقق في تقرير التسليم؛ لا تُعلّم العناصر غير المنفذة كمكتملة.
